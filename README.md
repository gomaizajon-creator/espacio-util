# Espacio Útil

Web estática en español con guías y selecciones sobre viajes, productos de deporte y productos varios. Se sirve con GitHub Pages y no requiere servicios de pago.

## Estructura
- `index.html`: portada, categorías y enlaces a las guías publicadas.
- `guia-alojamiento.html`, `guia-correr.html`, `guia-productos.html`: guías editoriales iniciales.
- `viaje-golf-royal-obidos.html`, `mercadillos-navidad-alsacia.html`: itinerarios de viaje.
- `equipaje-golf-portugal.html`, `equipaje-mercadillos-navidad.html`: guías de equipaje con páginas de Decathlon y búsquedas de Amazon.
- `styles.css`, `categories.css`: estilos responsive.
- `site.js`: menú móvil y año del pie de página.
- `afiliacion.html`, `privacidad.html`: avisos informativos.

## Afiliación y productos
Espacio Útil no tiene enlaces de afiliación activos. Las solicitudes a Booking.com, Decathlon Afiliados España y Amazon Afiliados España siguen pendientes. Los enlaces de tiendas incluidos en las guías de equipaje son enlaces normales, sin etiquetas de seguimiento. No se mantienen precios y la disponibilidad puede cambiar; consulta las páginas enlazadas antes de comprar. Los productos citados no se han probado personalmente.

## Publicación
El sitio está en la raíz de la rama `main`. GitHub Pages publica estos archivos estáticos. No se necesitan servicios de pago para alojar las páginas dentro de las condiciones del plan aplicable al repositorio.

Las guías de viaje incluyen datos sujetos a cambios. Comprueba fechas, horarios, disponibilidad, condiciones de reserva y transporte en las fuentes oficiales enlazadas antes de viajar. No se garantizan ingresos por afiliación.
